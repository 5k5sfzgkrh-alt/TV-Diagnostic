TV Diagnostic 1.3.0 — подготовленный исходный код

Изменения:
- Добавлена кнопка «Бэкап SYSTEM + VENDOR».
- Разрешены только /dev/block/by-name/system -> /dev/block/mmcblk0p20 и
  /dev/block/by-name/vendor -> /dev/block/mmcblk0p21.
- Root проверяется командой su 0 id.
- Размеры читаются blockdev --getsize64; допускаются только положительные
  размеры, кратные 512 байтам, не более 3 GiB на раздел.
- До чтения проверяется суммарное свободное место (размеры двух разделов + 64 MiB).
- dd используется только для чтения (if=..., без of=); данные сразу идут в ZIP.
- После закрытия ZIP каждый образ читается обратно из ZIP и проверяется по
  размеру и SHA-256. В архив включён SHA256SUMS.txt.
- Существующие функции DTBO и BOOT/RECOVERY сохранены.

ВАЖНО:
Это исходный пакет, а не готовый APK. В текущей среде отсутствует Android SDK
и Gradle, поэтому полноценная Android-сборка и установка на телевизор не выполнены.
Проверка Kotlin-компилятора без Android SDK не является проверкой сборки APK.
До физического теста не использовать для резервного копирования.
Никакие команды записи/стирания/прошивки разделов не добавлены.

Дополнительная проверка v1.3.0:
- Добавлен watchdog на 30 минут для процесса dd, чтобы зависшее чтение stdout
  не обходило лимит времени. Watchdog завершает только процесс чтения.
- Добавлен GitHub Actions workflow .github/workflows/android.yml для сборки
  debug APK на JDK 17 / Gradle 8.9 / Android SDK 35 и публикации APK + SHA-256.
