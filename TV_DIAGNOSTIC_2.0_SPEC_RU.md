# TV Diagnostic 2.0 — спецификация и границы безопасности

Цель: исследование работающей Android TV и подготовка доказательной карты компонентов для проекта Lite на CS2352P687 / Hi3751V553.

## Реализовано в начальном каркасе
- Снимок Build fingerprint, Android/API, manufacturer/model/device/product/board/hardware.
- RAM и доступное приложению хранилище.
- Список установленных пакетов с системным флагом, enabled и sourceDir.
- Список процессов, видимых обычному Android-приложению.
- Экспорт JSON через системный chooser.
- Режим строго READ_ONLY.

## Ограничения
- Обычный APK не видит все процессы, службы, HAL, init и kernel modules.
- Для расширенного чтения потребуется отдельный root-backend с allowlist только read-команд; в этой версии его ещё нет.
- Отсутствие процесса в отчёте не означает отсутствие компонента.
- Нельзя присваивать зелёный статус только по имени или размеру APK.

## Политика решений
- GREEN: отключение доказано анализом манифестов, providers/receivers/services, shared UID, библиотек и проверкой на устройстве; только обратимое отключение пакета.
- YELLOW: есть неразрешённые зависимости или нехватка runtime данных.
- RED: загрузка, дисплей, аудио, ТВ-тюнер, сеть, HAL, драйверы, системный UI, framework, init, firmware и partition metadata.
- GRAY: назначение не установлено.

## Неприкосновенные ограничения
Приложение не выполняет pm disable/uninstall, setprop, remount, dd, flash, fastboot, запись в /dev/block или изменение разделов. Автоотключение не входит в текущий каркас.

## Следующие этапы
1. Разбор APK manifests и сертификатов из подтверждённых system/vendor образов.
2. Индексация компонентов AndroidManifest, permissions, sharedUserId и uses-library.
3. Сопоставление с runtime package/process/service данными.
4. Отчёт по каждому кандидату с доказательствами и уровнем уверенности.
5. Только после тестирования — отдельный экран обратимого управления пакетами с журналом и rollback.
6. Перенос QR/Wi-Fi/backup функций после получения и проверки их исходников; в доступной ветке main полного исходного дерева этих функций пока не подтверждено.

## Сборка
GitHub Actions workflow Android APK выполняет gradle assembleDebug и публикует APK + SHA-256. Успешная CI-сборка ещё не является проверкой на физическом телевизоре.
